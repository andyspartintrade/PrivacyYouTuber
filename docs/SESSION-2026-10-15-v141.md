## 🛠️ BUILD WORKFLOW (ΔΟΚΙΜΑΣΜΕΝΟ)

```bash
# 1. onedir (~66 MB)
python build_onedir.py

# 2. installer (~27 MB) — ⚠️ -INPUTCHARSET UTF8 ΑΠΑΡΑΙΤΗΤΟ (το .nsi έχει BOM!)
"/c/Program Files (x86)/NSIS/makensis.exe" -INPUTCHARSET UTF8 \
    installer/PrivacyYouTuber.nsi /DVERSION=1.4.1

# 3. Gumroad → Content → Upload files → ⚠️ SAVE CHANGES
```

**ΠΑΓΙΔΕΣ:**
- `.nsi` με **UTF-8 BOM** → χωρίς `-INPUTCHARSET UTF8`: *«Bad text encoding»* **ή** σιωπηλά version **1.0.0**
- `build_installer.bat` **δεν τρέχει από git-bash** → κάλεσε `makensis.exe` απευθείας
- `build_onedir.py` **αντιγράφει** στο `Desktop/PrivacyYouTuber/`

## 🚨 ΠΑΓΙΔΑ: FRONTEND OVERRIDE

`%LOCALAPPDATA%\PrivacyYouTuber\web\index.html` **ΚΕΡΔΙΖΕΙ** το built-in (`_index_html_path()`).
Αν μείνει παλιό → το app δείχνει **παλιό UI** ακόμα και με νέο installer. Το WebView2 κρατά **cache**.

**Λύση:** σβήσε τον `%LOCALAPPDATA%\PrivacyYouTuber\web\`.
**⚠️ ΜΗΝ** σβήσεις τη βάση (`privacy_yt.db`) — εκεί ζουν τα βίντεο + το license.

```bash
# Sync frontend → override + Desktop (γρήγορη δοκιμή χωρίς rebuild)
OV="$LOCALAPPDATA/PrivacyYouTuber/web"; DT="C:/Users/andys/Desktop/PrivacyYouTuber/_internal/web"
for d in "$OV" "$DT"; do cp web/index.html "$d/"; cp web/i18n.json "$d/"; cp web/i18n.js "$d/"; done
```
